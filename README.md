# 计算机学院学生第三支部答辩谈话抽题

答辩谈话现场用的抽题页面。时事热点全员同题，个人题目每人一套，题目抽过不再重复。

## 用法

- 时事热点全场固定一道，直接显示，不能更换。
- 再按「抽取第一位」「下一位」，随机抽出一位还没抽到的同学，并给一套个人题。
- 个人题可点击，点过的题会变淡绿色并在右边打勾。
- 参考答案默认显示，右下角眼睛图标可收起。
- 本场固定 17 人。抽完后点「完成考试」，可回看这 17 位同学分别抽到的题目。
- 右上角图标切换白天 / 黑夜。

## 抽题规则

每位同学 4 题：

1. 1 道党章难题
2. 1 道二十大题
3. 2 道单独提问（主观开放题）

「你对前面回答的同学中，哪个同学回答的内容令你印象最深刻」不抽给第一位。

抽题记录和主题存在本机浏览器里，关掉页面再打开还在。换设备或清除网站数据会丢失。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:8080/`。
